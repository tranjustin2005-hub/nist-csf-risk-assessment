# NIST CSF 2.0 Cybersecurity Risk Assessment

This project demonstrates a practical cybersecurity risk assessment based on the NIST Cybersecurity Framework (CSF) 2.0.

## Project Overview

The project was created to simulate how organizations identify, document, evaluate, and prioritize cybersecurity risks.

It includes a cybersecurity risk register and a NIST CSF 2.0 gap assessment designed to demonstrate practical governance, risk, and compliance (GRC) concepts.

## Key Components

- Cybersecurity risk register
- Likelihood and impact scoring
- Risk prioritization
- NIST CSF 2.0 gap assessment
- Security control evaluation
- Identification of control gaps
- Remediation recommendations

## Skills Demonstrated

- Cybersecurity Risk Management
- Governance, Risk, and Compliance (GRC)
- NIST Cybersecurity Framework 2.0
- Security Control Assessment
- Risk Analysis
- Risk Documentation
- Microsoft Excel
- Technical and Business Risk Communication

## Risk Assessment Method

Risks are evaluated using likelihood and potential business impact. These factors are used to determine overall risk severity and help prioritize remediation efforts.

The gap assessment evaluates security practices against NIST CSF 2.0 outcomes to identify areas where security controls could be strengthened.

## Purpose

I created this project to gain hands-on experience applying cybersecurity risk management concepts beyond coursework and certification study.

The project helped me better understand how technical security issues can be translated into structured risk information that organizations can use to make informed decisions.

## Project Files

- `Risk_Register.xlsx` — Risk identification, likelihood and impact ratings, controls, and remediation recommendations
- `NIST_CSF_2.0_Gap_Assessment.xlsx` — Assessment of security practices against NIST CSF 2.0

## Framework

This project is based on the NIST Cybersecurity Framework 2.0.
